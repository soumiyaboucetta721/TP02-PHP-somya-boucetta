## Exécution

Pour exécuter les fichiers PHP localement :

```bash
php -S localhost:8000
```

Avec XAMPP sous Windows :

```powershell
& "C:\xampp\php\php.exe" -S localhost:8000
```

Puis ouvrir :

`http://localhost:8000/index.php`
